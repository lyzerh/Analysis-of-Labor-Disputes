## 使用教程

### 1. 获取案例
进入「高级工具」>「数据管理」>「工劳网采集」：
- 选择省份与审级。
- 设置裁判日期范围与采集数量。
- 点击开始采集后，系统会自动分页获取案例。
- 系统会自动跳过重复案例；采集过程中可以随时暂停和继续；若页面刷新，也可以从断点恢复继续采集。

### 2. 查看案例库
进入「法务工作台」>「劳动争议案例库」：
- 查看已经入库的案例总数。
- 支持按城市、年份、审级、关键词进行筛选。
- 点击具体案件，即可查看原始裁判文书和结构化分析结果。

特别说明：
「原始文书」是采集到的原始基础数据；「案例库」是经过解析并符合准入条件、可用于分析的结构化案例。两者数量不一定完全相同。

### 3. 案例分析
进入「法务工作台」>「案例分析」：
- 从案例列表中选择具体案例。
- 模块化查看劳动者诉求、企业抗辩、关键证据、法院裁判理由及裁判结果。
- **说明**：系统基于原文严格提取，无法识别的信息会如实显示为「未识别」，不会由系统自行编造。

### 4. 应诉参考
进入「法务工作台」>「应诉参考」，可以根据历史案例查看：
- 企业抗辩支持情况。
- 法院否定企业抗辩的高频依据。
- 企业获支持案件中的高频单项证据。
- 2项、3项证据组合。

明确说明：
这些数据表示历史案例中的统计关联，不代表某种证据或抗辩必然导致胜诉，也不构成法律意见。

### 5. 推荐使用流程
采集案例 → 查看案例库 → 检查案例质量 → 案例分析 → 应诉参考

### 6. 数据说明
- 您的数据均保存在本地浏览器 IndexedDB。
- 原始文书为系统底层数据，不直接修改。
- 案例分析数据可以根据最新解析规则随时重新构建。
- 如果更换浏览器或清除网站数据，本地数据可能无法继续保留。
