# 劳动争议案例分析系统

面向**劳动争议企业应诉与案例研究**的本地化分析工具。

## 核心功能

* **案例采集**：对接工劳网 API，批量获取裁判文书并保存至本地 IndexedDB。
* **案例库**：支持按城市、年份、审级、争议类型等条件检索。
* **结构化解析**：从裁判文书中提取诉讼请求、企业抗辩、关键证据、法院裁判理由及裁判结果。
* **企业应诉分析**：统计企业抗辩支持情况、法院否定依据及高频证据组合。
* **城市分析**：案例库支持全国城市；核心分析目前聚焦**广州、深圳、东莞**。
* **数据溯源**：分析结果可回溯至原始裁判文书，支持逐案查看。

## 数据流程

```text
工劳网 API
    ↓
RawDocument
    ↓
结构化解析
    ↓
AnalysisCaseRecord
    ↓
案例库 / 案例分析 / 应诉参考
```

## 设计原则

* 本地优先，数据保存在浏览器 IndexedDB
* RawDocument 不可变
* 分析与原始文书解耦
* 不调用 Gemini API
* 统计结果不进行未经证据支持的因果推断
* 企业“抗辩支持”与“企业作为原告的诉求支持”严格区分

> 本项目主要用于劳动争议案例研究、法律学习与企业应诉分析，不构成法律意见。
